# smart-study-bot

AI를 활용한 스마트 공부 스케줄러 봇!  
OpenAI GPT를 이용해 과목별로 공부 시간과 일정을 생성해줘요.

---

## 기능

- 하루 5시간 기준으로 스케줄 생성
- 과목: 국어, 수학, 영어, 과학, 사회
- 수학은 우선순위 높게 배정
- 랜덤 분배로 매번 다른 일정 생성!

---

## 터미널에서는 이런 형태로 나타나요
📅 Day 1
  - 수학: 3시간
  - 영어: 1시간
  - 사회: 1시간
